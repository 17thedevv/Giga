# Giga

**Giga** is an AI-powered web application that combines conversational assistance with a coding agent in one workspace.

## Overview

Giga is designed around two experiences:

- **AI Chat:** Multi-turn conversations, streamed responses, and conversation history.
- **Coding Agent:** A tool-using assistant that can inspect a GitHub repository, understand a coding task, propose file changes, and prepare a pull request after user approval.

The goal is to make AI assistance practical and transparent: users can see what an agent is doing, inspect proposed changes, and control when modifications are applied.

## Technology

Giga is a **TypeScript-first** project. Its web interface, backend API, agent orchestration, and external integrations are designed to run as a cloud-hosted application.

## Status

**Early development / planning.** The capabilities described above define the initial product scope and are not yet implemented.
