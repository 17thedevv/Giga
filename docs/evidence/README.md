# Evidence Repository

Store sanitized, traceable evidence for Cloud deployment/operation, peer cross-training, testing and the instructor report.

Suggested grouping when real evidence exists: `w01/`, `w02/`, `w03/`, `w04/`.

For every evidence item record: date/time, operator, reviewer, environment, tested commit, what was checked, PASS/FAIL, source URL/issue and known limitations.

**Never add** API keys, auth cookies, connection strings, private tokens, unredacted console access screenshots or sensitive user data. Do not fabricate evidence.
