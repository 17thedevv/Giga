# Cloud Runbooks

This folder will contain reproducible instructions for deployment, health checks, incident response and rollback.

## Required runbook fields
- Purpose and owner, reviewer/cross-trainee.
- Environment and commit SHA; prerequisites and permissions.
- Safe step-by-step commands / cloud console steps.
- Expected results with verification checks.
- Failure symptoms, diagnosis, safe rollback and cost notes.
- Sanitized screenshot/log evidence and Linear issue links.
